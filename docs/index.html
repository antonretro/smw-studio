Everything in one place

SMW Studio runs the game's own code to draw and play your levels, so what you see is what the game does.

🧱

Level editor

Place, move, copy and erase objects and sprites from palettes the game draws itself. Undo everything.

▶️

Play instantly

Jump straight into any level from the editor, with test cheats: invincible, infinite time, any power-up, start at the midway.

⚡

SA-1 hacks

Big SA-1 hacks open, draw, edit, save and play from the inside, with SA-1 emulated in the editor.

🎵

Music

Turn MIDI files into songs, insert them with AddmusicK, and see which songs in any hack are original or custom, then play any of them.

🧩

Patches as switches

Add community patches (like a ground pound or wall jump) and switch them on or off. Off puts every byte back; patches that would break a hack are refused.

🖼️

Status bar designer

Presets, drag-in counters and icons, moving counters, sprites anywhere on the bar. Works on a real SNES.

📦

Toolbox

Import packs from SMW Central once and use them in any hack, and take levels and songs from other hacks.

🗺️

Overworld

See every map exactly as the game draws it, with all paths and events shown.

📘

Learn as you go

A first-run tour, built-in tutorials and plain-language messages, not hex and guesswork.

FAQ

Is it legal?

SMW Studio contains no Nintendo game data. It reads your own copy of the game, like other SMW tools. Share your hacks as patches, never as ROMs.

Does it work with my Lunar Magic hack?

Yes: it opens Lunar Magic hacks and SA-1 hacks. It makes backups before big changes, but keep your own backups too: this is an alpha.

Does it replace Lunar Magic?

Not yet. The overworld editor, block editor and graphics tools are still to come. Lunar Magic is still recommended for those parts.

Is it free?

Yes, free and open source (MIT).
