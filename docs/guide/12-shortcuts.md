# Keyboard shortcuts

## Anywhere

- `Ctrl+O`: open a ROM
- `Ctrl+S`: save
- `Ctrl+Z` / `Ctrl+Y`: undo / redo
- `Ctrl+,`: preferences

## Tools

- `V`: Select
- `B`: Draw
- `G`: Fill
- `E`: Erase
- `S`: Sprites
- `Esc`: put down what you picked / deselect

## Level

- `Ctrl+scroll`: zoom
- Arrow keys: nudge the selected object or sprite
- `Delete`: delete the selected object or sprite
- `Ctrl+drag`: copy

## Test Play

- Arrows: move
- `X` jump, `C` spin jump, `Z` run / pick up, `S` X button, `Enter` start
- `R`: restart the level
- `Esc`: stop playing
