# Layers

Super Mario World draws a level in layers. The **Layers** panel (**Window → Layers**) works like layers in a paint program.

- **Markers**: where Mario starts (**M**), the midway restart (**½**), secondary entrances, and the labels showing where each screen's pipes lead.
- **Sprites**: enemies and items.
- **Level (layer 1)**: what Mario stands on: ground, blocks, pipes.
- **Background (layer 2)**: the picture behind the level. In some level modes it's a second solid layer that can move.

## What the buttons do

- **👁** shows or hides a layer. It's instant and changes nothing in the ROM.
- **🔒** (Sprites and Level) locks a layer: clicks go straight through it. Lock Sprites to grab a block behind an enemy.
- **Click a layer's name** to work on only that layer: clicks only pick things on it. Click it again to work on everything.
- **Fade the other layers** makes the other layers see-through while you work on one.

## Tutorial: edit blocks behind enemies

1. Open **Window → Layers**.
2. Click the 🔒 next to **Sprites**.
3. Click the block behind the enemy: it's selected, not the enemy.
4. Click 🔒 again when you're done.
